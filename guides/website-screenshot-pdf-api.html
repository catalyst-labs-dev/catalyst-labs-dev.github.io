Website Screenshot & PDF API: Full-Page PNG and PDF from Any URL

Our Website Screenshot & PDF API captures full-page screenshots (PNG, JPEG, WebP) and PDFs of any URL, with desktop, tablet and mobile presets.

Call it from code

curl -X POST "https://api.apify.com/v2/acts/catalyst-labs~website-screenshot-pdf-api/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" -d '{"urls":["https://example.com"],"formats":["png","pdf"],"fullPage":true}'

formats accepts png, jpeg, webp and pdf. Other options include device, fastMode and the pdf* settings; see the Store page input tab.

How we tested

In an Oct 18, 2026 benchmark we ran the same 12 URLs, at the same settings, through ours and five other Store screenshot tools, including the most-used one. Pages with heavy animation can still need tweaking; we publish where we lost, not only where we won.
